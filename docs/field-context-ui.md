# Feldkontext in der FarmVisite

Die Oberfläche verwendet jetzt das gemeinsame Farm-/Feldmodell.

Beim Anlegen einer Beobachtung wird gespeichert:

- die Farm-ID
- die Feld-ID
- der Feldname als lesbarer Snapshot

Die Feldauswahl zeigt zusätzlich die Kultur, sofern vorhanden. Dadurch kann der Beobachtungskontext später direkt an Sensor-, Wetter- und KI-Adapter weitergegeben werden.

Der aktuelle Seed enthält weiterhin nur Demo-Daten; eine echte Betriebsanlage bzw. Synchronisation ist noch nicht implementiert.
